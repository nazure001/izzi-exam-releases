# SMPN 2 Karangtengah — Exam Kiosk Releases

Repositori distribusi APK aplikasi **Exam Kiosk** untuk SMPN 2 Karangtengah.

## Download APK

Unduh APK versi terbaru melalui tautan berikut:

👉 **https://exam.izzi.my.id/download/kiosk**

Atau langsung dari halaman [Releases](https://github.com/nazure001/izzi-exam-releases/releases/latest).

## Persyaratan

- Android 8.0 (Oreo) ke atas
- Aktifkan "Install dari sumber tidak dikenal" di pengaturan perangkat
- Koneksi internet aktif saat login

## Cara Install

1. Download APK dari link di atas
2. Buka file APK di perangkat Android
3. Izinkan instalasi dari sumber tidak dikenal jika diminta
4. Selesai — buka aplikasi dan login menggunakan NISN

---

> Aplikasi ini hanya untuk penggunaan internal SMPN 2 Karangtengah.
